**Project title:** Multimodal Machine Learning for Multi-Omics Integration in Precision Medicine

**Brief project description:** This project uses multimodal machine learning to integrate genomic, transcriptomic, and proteomic data from the NIH All of Us Research Program. By predicting gene and protein expression from DNA, it aims to separate inherited from acquired molecular variation and link these signals to health outcomes, supporting more personalized and equitable precision medicine.
